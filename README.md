# Ranger Historical Archive

Русскоязычный иллюстрированный исторический архив рейнджеров армии США периода Второй мировой войны.

Публичный сайт: https://colin-ru.github.io/ranger-archive/

Содержимое: история шести батальонов, 24 ступени званий, 104 предметных и исторических карточки, 124 листа атласа. Источники и происхождение изображений доступны в карточках и реестре на сайте.

Хроника: Office of War Information, D-Day (1944), public domain. Музыка: Charleston (Golden Gate Orchestra, 1925), Yes Sir, That's My Baby (Gene Austin & Billy “Uke” Carpenter, 1925), Ain’t We Got Fun (Billy Jones, 1921). Public-domain recordings; sources and credits are listed in the website archive radio playlist. Лицензии шрифтов приложены в каталоге fonts.

## Deployment

GitHub Actions unpacks assets-*.zip into the site artifact and publishes it through GitHub Pages. HTML, CSS, JavaScript and data.json are editable source files. PDF and ZIP editions are distributed through the v1.0 release.

No accounts, analytics, tracking, API keys or external application services are used. Music starts only after a visitor presses the play button. The persistent player offers three recordings, previous/next controls, track selection and automatic advance. Internal section navigation updates the main content and real page URL while retaining playback, pause, position and volume; the five HTML pages also work as direct entry points. Background film respects reduced motion preferences.
