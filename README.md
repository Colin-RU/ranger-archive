# Ranger Historical Archive

Русскоязычный иллюстрированный исторический архив рейнджеров армии США периода Второй мировой войны.

Публичный сайт: https://colin-ru.github.io/ranger-archive/

Содержимое: история шести батальонов, 24 ступени званий, 104 предметных и исторических карточки, 124 листа атласа. Источники и происхождение изображений доступны в карточках и реестре на сайте.

Хроника: Office of War Information, D-Day (1944), public domain. Музыка: Charleston, Golden Gate Orchestra, Edison 51542-R (1925), public domain. Лицензии шрифтов приложены в каталоге fonts.

## Deployment

GitHub Actions unpacks assets-*.zip into the site artifact and publishes it through GitHub Pages. HTML, CSS, JavaScript and data.json are editable source files. PDF and ZIP editions are distributed through the v1.0 release.

No accounts, analytics, tracking, API keys or external application services are used. Music starts only after a visitor presses the play button. Background film respects reduced motion preferences.
